# Code of Conduct

## Our pledge

We are committed to a welcoming, respectful, and harassment-free community for everyone.

## Expected behaviour

Use considerate language, respect differing viewpoints, accept constructive feedback, and focus discussions on improving the project.

## Unacceptable behaviour

Harassment, discrimination, personal attacks, intimidation, and publishing private information without permission are not tolerated.

## Enforcement

Report concerns privately through the Nidhya Technologies GitHub organization. Maintainers may remove content or restrict participation when this code is violated.
